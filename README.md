# Junteng Liu — Academic Homepage

Personal academic homepage of Junteng Liu, built with the [Academic Pages](https://github.com/academicpages/academicpages.github.io) Jekyll template for GitHub Pages.

## Pages

- **About** (`/`): biography, research interests, academic background, research experience, publications, skills and contact information.
- **Publications** (`/publications/`): publication list, also recorded in the About section.
